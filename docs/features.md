# 功能清单与能力边界

状态：`v1.2.0-alpha.1`。下面描述源码已经提供的功能，不是对所有模型与设备的成功保证。

| 功能 | 现在能做什么 | 实际价值 / 边界 |
|---|---|---|
| 项目与上下文 | 保存 brief、品牌/IP 要求、脚本、镜头、素材和消息 | 集中已确认要求；不是企业知识库或多人权限系统 |
| 导演协作 | 讨论提案，选择脚本/镜头/关键帧，提出修改 | 用户审阅采用；认知模型须自行配置 |
| 分镜与关键帧 | 编辑时长、动作、参考图和候选，批准采用图 | 支持创作迭代；参考节点不代表模型能精确控制该帧 |
| 源区间 | 保存素材 ID、源开始/结束与状态，同一素材可复用多个区间 | 商品/IP 原声可复用；拒绝空、倒置和越界区间 |
| 修改提案 | 展示作用域、改动、影响与保留项；过期提案拒绝应用 | 防止旧建议覆盖新内容；不承诺视频像素级局部重绘 |
| 视频候选 | 新生成先登记，明确采用，旧版恢复 | 降低整片返工；本地处理明确采用素材可直接成为当前片段 |
| 内容修订 | 最多展示最近 50 版本，恢复为新版本 | 费用不回滚；相关制作与交付须重新确认 |
| 本地 ASR | MLX Whisper 句段级转写，单机共享 GPU 锁与持久化任务 | 原片不上传到云端 ASR；依赖 Apple Silicon 与权重缓存 |
| SRT 导入 | 导入时间戳字幕，绑定原片 | 自动转写失败仍可走完整剪辑；纯文本不够 |
| 文稿剪辑 | 定位原片、保留/删除/重排、边界修订 | 应用选择后改变剪辑；不是任意单字精确编辑 |
| 字幕修订 | 更新文字并保留原始转写 | 修正术语不会改音频；完整语义与边界须人工核对 |
| 模型路由 | 复用/合成优先，兼容性过滤，主方案/备用/排除原因 | 当前按规则和配置档位推荐，不是实时质量排名或自动学习策略 |
| 报价与预算 | 项目限额、预留、费用快照、对账与停止检查 | 应用内约束；与供应商实际账单可能不同，不能保证银行卡硬限额 |
| 任务执行 | 独立 Worker、租约、版本号、幂等键、事件推送 | 减少重复任务；供应商未知提交仍需查询/对账 |
| 内置 Skill | `brand-shot@1.0.0` 与 `ip-rough-cut@1.0.0` 通过允许命令提出建议 | 专业方法可改造；没有任意终端权限或插件市场 |
| 声音 | 独立旁白、字幕、音乐、原声、音效与音量 | 改声音不清空视频；不支持的原生对白生成会拒绝 |
| 本地合成 | FFmpeg 拼接、中文字幕、48 kHz AAC；累计时间校正 | 基础输出规格 480/720/1080，受实际路线配置约束；不冒称模型原生 1080 |
| 审片 | 时间定位、人工问题、可选 AI 审阅、交付确认 | AI 审阅不是质量保单；最终确认由使用者负责 |
| 导出与恢复 | MP4、SRT、素材/版本/费用项目 ZIP | 可携带过程；私有资产仍须保护，恢复后重新批准 |
| 本机边界 | localhost、本机会话、CSRF、凭据服务端存储 | 面向单操作者；不适合公开部署、多人并发或 SaaS |

## 模型适配器

认知接口涵盖 OpenAI-compatible chat、Responses、Codex；图像、视频、配音、音乐还含
Ark、Runway、MiniMax、OpenAI 和 ElevenLabs 等配置入口。准确的映射以 `studio/catalog.py`、
`studio/adapters.py` 和用户的账户为准。存在代码入口、连接检查通过、媒体成功生成、内容质量通过是四件不同的事。
不要把列表视为已测完的供应商矩阵；某些预设精确 ID 为空或需用户改为其账户实际可用版本。

## 本轮首发维护改进

创建失败直接在前景弹窗显示并保留输入；服务断开有持续提示；启动器保留 API/Worker 日志；
提供显式下载权重和不依赖付费账号的合成素材验证。持久化开机服务、原生安装包、逐字剪辑、
多用户权限、完整画布和外部插件市场仍未实现。
