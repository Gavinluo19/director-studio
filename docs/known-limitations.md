# 已知限制与支持范围

- Alpha，面向愿意配置本机环境的使用者；没有内容质量或服务可用性 SLA。
- Apple Silicon Mac 为已验证目标。Linux CI 的核心检查不代表完整跨平台支持。
- 单机单操作者。本机会话不是用户账号系统；不能公开暴露服务端口。
- 前台启动器随终端结束。日志已保留；没有自动安装常驻或登录自启服务。
- 自动 ASR 需要可选依赖及模型权重。句段时间戳可能误切或误识别，使用人工修订/边界调整/SRT。
- 逐字编辑、说话人分离、变速、倒放、复杂转场与完整波形/专业时间线未实现。
- 视频路由为能力/规格/费用规则，不是质量排名或保证成功率。
- 预设型号和报价有时间性，必须使用自己的账户核验。价格资料刷新不等于样片验证。
- 内置适配器并非每个账户都做过端到端真实付费测试；不支持的原生对白或中间精确状态不得强行启用。
- 局部修改是镜头/段落范围的工作流，不承诺对一段已生成视频进行任意像素级重绘。
- 凭据不导出，但项目 ZIP、日志、素材、文稿和费用历史可能敏感。
- 软件开源、模型权重许可证、供应商服务条款、素材使用权与最终商用审阅是不同事项。
- 没有外部插件市场、无限画布、多机同步、原生安装包或全自动发布账号能力。

## 首发处理的故障

创建错误曾落在前景弹窗后方的底部 Toast；公开副本改为弹窗内稳定显示，并保留输入、提供重新连接。
连接失效时保留页面顶部状态；API/Worker 输出改为本机日志。它解决“看不到错误/找不到日志”，
没有证明历史进程退出的具体原因，也没有把前台启动器变成持久服务。

发现未列出的故障，请提交脱敏 Issue。不要为未知收费结果盲目重试。
