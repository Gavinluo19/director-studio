# 路线图：先降低返工，再扩展自由度

路线图是讨论方向，不是承诺日期或已实现功能。

## 第一优先级

1. 冷安装与服务生命周期：更直接的前景状态、重连、日志及可选的手动常驻模式；先验证无丢稿与无重复 Worker。
2. 真实商品与真人访谈任务集：记录时间、采用费用、语义/边界错误与返工；覆盖噪声和更长原片。
3. 模型验证资料：区分接口契约、账户实测、样片质量和价格；让推荐依据可更新且可回看。

## 证据充分后

- 更自然的句段边界与可审阅粗剪，逐字编辑需独立技术验证。
- 导入/导出专业编辑器工程或替换合成后端。
- 可替换的领域方法与受控扩展契约；保持模型/预算/版本边界。
- 更容易使用的安装/更新路径。

## 当前不承诺

完整无限画布、外部插件市场、多用户账号、多机协作、自动社交账号发布、无审阅全自动生成、
未经验证的最优模型推荐或降本百分比。
