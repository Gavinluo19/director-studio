# 使用教程：完成你的第一条视频

## 先选择适合你的入口

| 你手里有什么 | 从哪里开始 | 是否需要云端模型 |
|---|---|---|
| 商品图、卖点、品牌要求 | 商品 / 电商短片 | AI 策划与生成需要你配置模型；手动编辑和原图合成可本地进行 |
| 本人口播、访谈原片 | 个人 / 自媒体 → 原片口播 / 访谈 | 本地转写或 SRT 导入；粗剪 Skill 可选，需要认知模型 |
| 一篇知识文稿 | 个人 / 自媒体 → 文稿型知识视频 | AI 设计/配音可选；自有图片、视频、录音可复用 |

## 界面怎么用

左侧是当前作品、阶段、上下文和历史。把必须保留的事实、商品文字、术语和本人表达风格保存到上下文。
中间是导演聊天、当前交付与修改提案。选中镜头或转写后，导演围绕所选内容提出建议。
右侧是真实脚本、分镜、关键帧、文稿、原片、路线、声音与成片。拖动分隔线调整宽度；窄屏可以折叠导演。
阶段导航可以查看工作，但没有完成内容/素材/预算确认时，执行仍会被阻止。

## A. 商品展示 / 品牌短片

以一条 15 秒的自有商品短片为例：

1. **创建作品。** 选“商品 / 电商短片”，填写名称，保存目标、受众、时长、比例和参考素材。
2. **说明事实。** 写清商品名称、能展示的卖点、必须保持的包装和禁用承诺。不要要求模型猜商品信息。
3. **与导演定方向。** 配置认知模型后生成提案，修改到符合目标，再确认。也可手动编辑已有脚本。
4. **打磨分镜与关键帧。** 检查每个镜头的时长、画面、动作；选定图片候选及参考用途，批准关键帧。
   首/尾帧输入与“审片参考”不是同一种控制；中间精确动作当前未必可执行。
5. **只改需要改的镜头。** 选中镜头，说明改动与保留项，如“保留商品外观，只改善环境与动作描述”。
   “品牌镜头设计”输出修改提案；先审阅，采用后再决定是否重新生成。不是直接改写每个旧视频的像素。
6. **写清能力要求。** 商品保真、人物一致、动作难点、连续性组、声音要求。它们帮助过滤路线并提示人工复核。
7. **确认路线和费用。** 先看原片复用或原图合成能否满足表达。生成时查看主模型、备用、排除理由、原生时长和报价。
   调整配置或价格后需要再次确认，供应商尚不支持的能力不会被静默伪装成成功。
8. **比较候选。** 生成结果进入候选。满意才采用；旧候选可恢复镜头设计后采用。无关片段可以保持复用。
9. **声音与字幕。** 上传自有录音/配乐，或配置 TTS/音乐模型。检查是否保留原声、音量、旁白时长和字幕时间。
10. **合成与审片。** FFmpeg 生成预览。完整看商品文字、人物、动作、声音与字幕；记录和处理问题。
    内容或声音改过后先重新合成，再确认交付。导出 MP4、字幕 SRT 与项目 ZIP。

商品精准展示常常更适合真实素材或原图合成；不必把每个镜头都交给视频生成模型。
软件的路线规则不是商品保真鉴定，最终商品与宣传内容仍由使用者检查。

## B. 个人 IP：原片口播 / 访谈

1. 新建“个人 / 自媒体内容”，选择“原片口播 / 访谈”。上传有权使用的原片或录音。
2. 若本地能力就绪，点击“本地转写”；否则导入带时间戳 SRT。转写是持久化任务，一次使用一份本地计算资源。
3. 点击句段时间码，原片定位到对应源时间。对照原声校订术语、数字、否定词和人物姓名。
4. **修订字幕文字。** 文字修改只更新字幕，不自动删掉声音。原始转写仍可查看。
5. **选择要剪的内容。** 勾选保留/剪除、上移/下移、必要时调整句段开始与结束。它们暂存为剪辑选择。
6. 可选“个人 IP 粗剪” Skill 给出保留段落提案。它不保证越短越好；应保留观点、限定条件和自然语气。
7. 点击“应用到剪辑”。才按段落重建镜头和字幕时间；源区间与成片时间分别保存。
   若替换另一份已有剪辑，会给出明确确认提示；可以从版本历史恢复。
8. 确认创作，推荐并确认“复用已有视频”路线。没有云端生成调用时，路线媒体报价为零。
9. 声音阶段勾选“保留原视频中的音频”。预览、处理审片问题、确认版本、导出。

例如原片 3—7 秒，放到成片开头：画面和原声都截取原片的 3—7 秒，字幕从成片 0 秒起计。
重新排序后，字幕随采用顺序重新计算。30 fps 画面边界精度与句段转写精度不同，不承诺逐字自动切除。
只有录音时可以合成基础画面加字幕；这是一条完整技术输出路径，不代表最终 IP 视觉风格。

## C. 文稿型知识视频

选择“文稿型知识视频”，编辑脚本，准备分镜和图片/视频，加入旁白或本地录音与字幕，再走路线、制作、声音、审片流程。
先保证知识准确和解释结构，再决定哪些概念需要画面。当前不自动连接专业图表/动画插件，也不保证生成的文字与数字正确。

## 候选、历史与项目包

- **采用候选**：切到已经匹配当前输入的结果；旧设计候选需要明确恢复/沿用。
- **恢复镜头并采用**：恢复该候选关联的镜头和源区间；其他镜头仍保留，相关制作路线需要复核。
- **版本历史与恢复**：最近 50 个项目修订；恢复生成新版本，保留原始素材、历史和费用，重新确认制作与交付。
- **项目 ZIP**：含真实素材、项目文档、候选、费用历史及最近版本；不含 API Key。备份仍是私有内容，不要公开上传。
- **恢复副本**：在“我的作品”导入 ZIP，检查素材引用和内容。原在途费用不会变成自动重新提交的任务。

## 预算与异常

费用显示区分已计、在途预留、实际使用估算/保守暂计和待核对记录。账本只覆盖应用内任务，不等于你账户的所有支出。
每次执行先看镜头、模型、规格和报价；改模型、追加收费重试或改变价格时重新检查授权。
不要把未知提交当作没收费。先查询原任务或与服务商对账；下载失败尽量只恢复下载。

后台断开时，页面顶部持续提示；创建弹窗会直接显示错误并保留名称。运行启动脚本后重新连接。
没有完成的任务和失败原因保存在本机，检查日志时注意不要分享凭据或客户材料。
